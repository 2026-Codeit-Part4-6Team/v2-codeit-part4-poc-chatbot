# 요구사항 명세서 초안

## 1. 문서 개요

**목적**: 소상공인이 생성형 AI를 활용해 광고 콘텐츠(문구·이미지·배너)를 손쉽게 제작할 수 있는 서비스의 기능/비기능 요구사항을 정의한다.

**범위**: 컨설턴트 챗봇(상권·경쟁사 분석)과 광고 콘텐츠 생성 챗봇(문구·이미지·배너 생성) 두 축을 중심으로 한 웹 서비스 전체.

**용어 정의**: 소상공인(서비스 사용자), 노드(챗봇 파이프라인 내 개별 기능 단위), 라우터(사용자 요청을 적절한 노드로 분기하는 로직).

---

## 2. 시스템 개요

사용자는 로그인 후 두 가지 메인 기능 중 하나를 이용한다. 컨설턴트 챗봇은 네이버 지도 API 기반으로 상권, 경쟁사 정보를 분석해 사용자에게 차별화 전략을 제안하고, 광고 콘텐츠 생성 챗봇은 이 분석 결과와 실시간 트렌드 정보를 반영해 플랫폼별 광고 문구, 이미지, 배너를 생성한다. 내부적으로는 라우터가 사용자 질의를 Agentic-RAG, Naive-RAG, 이미지 생성 노드, 문구 생성 노드, 게시물 생성 노드 중 적절한 경로로 분기한다.

## 4. 비기능 요구사항

- **성능**: 모델을 ONNX/TensorRT로 변환, Triton 서버로 서빙해 응답 속도 최적화. FastAPI ↔ Triton gRPC 연결.
- **배포/운영**: 코드 반영은 GitHub Actions 자동 배포(main merge 시 빌드→push→VM pull&restart)만 허용, VM 직접 코드 수정 금지. SSH는 트러블슈팅(파이프라인 디버깅, GPU/디스크 확인, 로그 확인) 용도로만 팀원 전원에게 개방.
- **보안**: 로그인 정보, 결제 정보 보호.
- **사용성**: 비전문가도 팝업 기반 간단한 클릭/대화 흐름으로 결과물을 받을 수 있어야 함.
- **확장성**: 노드 기반 구조로 신규 기능(노드) 추가가 용이해야 함.
- **모니터링**: 구조화된 로그 필수, 여유 시 Prometheus/Grafana 연동.

## 5. 데이터 요구사항

- DB: SQLite3
- `users` 테이블 - 사용자 정보
- `payments` 테이블 - 결제 정보
- `content` 테이블 - 생성물 정보

### users 테이블

| 컬럼명 | 타입 | 설명 |
| --- | --- | --- |
| id | INTEGER (PK, AUTOINCREMENT) | 사용자 고유 ID |
| email | TEXT (UNIQUE) | 로그인 아이디 |
| password_hash | TEXT | 비밀번호 해시(bcrypt 등, 평문 저장 금지) |
| business_name | TEXT | 가게/사업체명 |
| business_type | TEXT | 업종 (카페, 식당 등 — 상권분석 FR-04에 사용) |
| address | TEXT | 사업장 주소 (또는 lat/lng 별도 컬럼으로 분리 — 상권조회 FR-01에 사용) |
| is_admin | BOOLEAN (기본 FALSE) | 관리자 여부 |
| plan | TEXT (기본 'free') | 무료/유료 등급 |
| created_at | DATETIME | 가입일시 |

### payments 테이블

| 컬럼명 | 타입 | 설명 |
| --- | --- | --- |
| id | INTEGER (PK, AUTOINCREMENT) | 결제 고유 ID |
| user_id | INTEGER (FK → users.id) | 결제한 사용자 |
| amount | INTEGER | 결제 금액 |
| status | TEXT | pending / completed / failed |
| payment_method | TEXT | 결제 수단 |
| content_id | INTEGER (FK, nullable) | 어떤 생성물에 대한 결제인지 연결 |
| created_at | DATETIME | 결제 일시 |

### contents 테이블

| 컬럼명 | 타입 | 설명 |
| --- | --- | --- |
| id | INTEGER (PK) | 생성물 ID |
| user_id | INTEGER (FK → users.id) | 요청 사용자 |
| type | TEXT | 문구 / 이미지+문구 |
| platform | TEXT | 인스타그램 / 블로그 / 현수막 등 |
| content_text | TEXT | 생성된 문구 |
| image_url | TEXT (nullable) | 생성된 이미지 경로(유료인 경우) |
| is_paid | BOOLEAN | 유료 생성 여부 |
| created_at | DATETIME | 생성 일시 |

## 6. 인터페이스 요구사항

- 외부 API: 네이버 데이터랩 트렌드 API, 상권 정보 조회 OpenAPI, 네이버 지도 리뷰 API, 날씨/뉴스 API(또는 크롤링)
- 내부 연동: FastAPI ↔ Triton(gRPC)
- UI 화면: 로그인 페이지, 메인 페이지 사이드바("게시물 생성" 탭), 게시물 생성 팝업(OK/Cancel)
